Physics-Informed Neural Engine

NeuralCore

A PINN-style neural system that learns UI interaction policies from demonstrations. Four physics constraints enforce human-like behavior. Three neural networks work in concert to perceive, predict, and plan.

Ltotal = Ldata + λ₁·Lfitts + λ₂·Lcausality + λ₃·Lsafety + λ₄·Lui + λ₅·Lworld

NEURAL NETWORKS

PolicyNet
policy.py
Autoregressive GRU
Input State embedding (256d) + Intent embedding (128d)
Output Action sequence: type (31 classes), position (x, y ∈ [0,1]), timing (ms), risk (3 levels), stop probability
Purpose Generates sequences of UI actions from high-level intent — the "motor cortex" of the system
PerceptionNet
perception.py
MobileNet-style CNN
Input 224×224 RGB screenshot
Output 128-dimensional visual feature vector
Purpose Extracts UI element features from screenshots — the "visual cortex" that grounds actions in what's actually on screen
WorldModel
world_model.py
Encoder-Decoder
Input (state, action) pairs
Output Predicted next UI state
Purpose Predicts what happens next — enables look-ahead planning, anomaly detection, and safety verification before execution

PHYSICS CONSTRAINTS

🎯
Fitts's Law
MT = a + b · log₂(D/W + 1)
Enforces human-like mouse movement physics. Generates minimum-jerk trajectory profiles. Penalizes superhuman speed and impossible acceleration.
λ = 0.5 · Generates realistic cursor paths
🔗
Causality
P(action_i | state) → valid_transitions
Encodes UI state machine structure. Menus must open before items can be clicked. Dialogs must be dismissed before background interaction. No impossible orderings.
λ = 2.0 · Heaviest structural constraint
🛡️
Safety
risk(action) → {red, yellow, green}
Prevents dangerous and irreversible actions at training time. Regex-based classification of destructive patterns. Heavy penalty on red-classified actions.
λ = 10.0 · Strongest constraint — safety is non-negotiable
📐
UI Physics
click ∈ bbox(element) ∧ ¬teleport
Models structural rules of GUIs — bounding boxes, containment hierarchies, click target validity. Penalizes out-of-bounds clicks, teleportation, and inefficient paths.
λ = 1.0 · Structural correctness
